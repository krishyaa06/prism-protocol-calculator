## ⚡ Overview
**Prism Protocol Quantum Terminal** ek responsive aur versatile web calculator hai jo modern cyberpunk UI ke sath multiple calculation modes offer karta hai:

- 🧮 **Standard Arithmetic**: Quick basic math calculations.
- 🔬 **Scientific Workstation**: Trigonometry, log, ln, square root, powers aur constants.
- 💻 **Programmer Tools**: Instant conversions between Decimal, Hexadecimal, Binary, aur Octal.
- 📈 **DeFi Compound APY Engine**: Crypto staking APY aur yield calculations.
- ⌨️ **Full Keyboard Support**: Seamless keyboard inputs desktop users ke liye.
