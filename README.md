## Overview

**Quantum Terminal** is a modern, responsive web calculator built for Prism Protocol.  
It features a clean cyberpunk interface and four powerful calculation modes.

### Modes

| Mode | Description |
|------|-------------|
| **STD** | Standard arithmetic operations |
| **SCI** | Scientific functions (sin, cos, tan, √, log, ln, x², π) |
| **PROG** | Number system conversions (HEX, BIN, OCT, DEC) |
| **DEFI** | Simple APY & compound interest calculations |

### Features

- Clean glassmorphism + neon UI
- Full keyboard support
- Responsive design
- Lightweight (vanilla HTML, CSS & JavaScript)
- MIT Licensed
